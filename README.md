# LOOP DXF → STAAD.Pro

A Windows desktop application by **LOOP Structural Automation** for converting DXF geometry into STAAD.Pro nodes, members, and `.STD` files.

### Features
- DXF import and CAD preview
- Automatic node and member generation
- Node merging and member splitting
- Geometry diagnostics and conversion logs
- STAAD.Pro `.STD` export
